## How each project is solved

Every project follows the same 10-step AI agent workflow: set the goal and guardrails, collect data (Data Agent), clean and prepare it, analyze it (Analytics Agent), validate the findings, reason about options (LLM Planner Agent), get human approval, act through tools (Action Agent), run a pilot with a control group, then learn and retrain.
